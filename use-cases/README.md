# DevAgentForce use cases

Seven ways teams and solo engineers run DevAgentForce every day.

Each page: Problem · Who it's for · How it runs · What you get · Edition · Related.

| Badge | Meaning |
|---|---|
| **Free** | Runs on the free edition with API keys. |
| **Pro** | Needs a Pro licence. Free 14-day trial from your capitaltools.app account ([product page](https://capitaltools.app/devagentforce)). |
| **Free** + Pro | Core works on Free. Pro adds the named extras. |

| # | Use case | Outcome | Edition |
|---|---|---|---|
| 01 | [Ticket to verified PR](01-ticket-to-verified-pr.md) | A ticket becomes a PR that passed your build, tests and lint. | **Free** + Pro |
| 02 | [Plan, then implement](02-plan-then-implement.md) | You approve the plan — dashboard, Ask Agent or Telegram — before code is written. | **Pro** |
| 03 | [Overnight multi-vendor batch](03-overnight-multi-vendor-batch.md) | A queue runs unattended across vendors, fails over, reports by morning. | **Free** + Pro |
| 04 | [Local repository, no remote](04-local-repo-no-remote.md) | Agents commit to your local branch. Nothing is pushed. | **Free** |
| 05 | [Pre-ship review loop](05-pre-ship-review-loop.md) | A second agent reviews, the first fixes, the verifier re-runs. | **Pro** |
| 06 | [Research with artifacts](06-research-with-artifacts.md) | Light tasks deliver a `RESULT.md` — e.g. a design "grilling" ending in a decision record. | **Free** + Pro |
| 07 | [Scheduled skills: a job search](07-scheduled-skills-job-search.md) | Skills run on a schedule, keep every result, send a Telegram digest. | **Free** |

Steps match dashboard screen names. Diagrams are Mermaid; GitHub renders them inline.
