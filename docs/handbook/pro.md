# Pro edition and licensing

One codebase. **Free** (proprietary `LICENSE`) is a complete pipeline. **Pro** adds memory, governance, integrations.

## Free

Full task pipeline · all vendors · error-class-aware retries · repo map · auto-failover · rate-limit backoff · analytics · pipeline board · architecture diagrams · templates · ideas tree · cron schedules · live logs · settings and system LLM · basic Telegram · backup and restore · worktree isolation with Gitea/GitHub PRs · local repos · verifier · secrets store · this assistant with tools and one-click fixes.

## Pro adds

- **Reality gate** — checks evidence before spending a run; **strict abstain gate** stops unsupported tasks.
- **Per-repo memory** — pgvector, hybrid vector+lexical search, transcript drawers, temporal facts, decision memory, wake-up digest, cross-repo tunnels. Local embeddings, no cloud key.
- **Semantic code and doc search** over each repo.
- **MCP task-control server** (`devagentforce-mcp`).
- **Plan gate** — approve the plan; its file list becomes an enforced allow-list.
- **Budget breaker** — blocking per-task cost and wall-clock ceilings.
- **PR preflight** — secret scan, author, file size, scope creep, before any push.
- **Patch export** — `git format-patch` and `combined.mbox`.
- **Rich Telegram** — approve/reject keyboards, daily digest.
- **Workflows** — plan, parallel multi-agent review, implement. I can create and start them.
- **Inter-task messaging** — agents message each other and you.
- **Webhook triggers** — each delivery runs the webhook skill.
- **A2A gateway** — governed delegate for other agents. Vertex AI / Gemini Enterprise connect via Google Cloud service account (peer kind *Google Cloud OIDC*).
- **Review loop** — reviewer before delivery, task session fixes. Weak findings filtered; `.daf/review-rules/*.md` adds rules.
- **Integrations** — Azure DevOps items → pending tasks or ideas.
- **Sessions** — every host session live, approve/reject, steering, Stop.

## Get it

Paid, self-hosted, per deployment — not per seat — from **capitaltools.app**. New installs run free. 14-day trial from your capitaltools.app account, no card.

**Settings → License** → paste key → **Activate**. Offline hosts activate there too. Lapsed licence → free. Nothing deleted.

The footer shows build edition and licence state. Pro build without licence or trial = free.
