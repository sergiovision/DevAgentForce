# Repository memory (Pro)

What agents learned per repo: notes, facts, decisions, gotchas, optional transcripts. Searchable at once. A hint, not a verified claim. Secrets removed first.

## Settings → Memory

- **Recall** — exact-word matching beside meaning, weak-match floor, memories per prompt, related repos' same-topic memories.
- **Retention** — prefer recent; archive unused (never *helpful* ones).
- **Learning** (on) — rank by feedback, lesson on failure (repeats counted), keep transcripts.
- **Hygiene** — report-only check every 6 h; duplicate similarity, unused threshold.

## Memory card (repo page)

Search, filter (kind, flagged, failure lessons); facts in their own table. Per row: helpful, not helpful, flag stale/wrong with reason, invalidate (kept, not recalled).

**Health** — duplicates, outdated, flagged, unused; *Run now*. **Merge** (keep best, archive rest), **Invalidate**, **Dismiss** (until they change). Nothing deleted; the check changes nothing.
