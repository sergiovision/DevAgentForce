# Security policy

## Report a vulnerability

- **Email:** `security@<TODO>`
- **Never** in a public issue or discussion.
- Include: version (dashboard footer), platform, steps, impact.

You get an acknowledgement and updates until it's fixed. Credit in the release notes, if you want it.

## Scope

- DevAgentForce builds from [capitaltools.app](https://capitaltools.app/devagentforce): installers, desktop app, cloud VM install.
- These docs, where they would lead to an insecure setup.

Agent CLIs, AI vendors and git hosts: report to them.

## Supported versions

Latest 2.0.x only. Update: re-run the installer — [Getting started](docs/getting-started.md#updating).
