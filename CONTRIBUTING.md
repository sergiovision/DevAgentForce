# Contributing

Docs only. The product source is not public — no code PRs.

| You have | Go to |
|---|---|
| A question | [Discussions → Q&A](https://github.com/sergiovision/DevAgentForce/discussions) |
| An idea | [Discussions → Ideas](https://github.com/sergiovision/DevAgentForce/discussions) or a *Feature request* issue |
| A bug | A *Bug report* issue — or Logs → Bug report in the product |
| A docs fix | An issue. Small doc PRs may be accepted. |
| A security issue | [SECURITY.md](SECURITY.md). Never public. |

**Before you post:** check the [FAQ](docs/faq.md) and [handbook](docs/handbook/README.md). Strip secrets, hostnames and private repo names.
